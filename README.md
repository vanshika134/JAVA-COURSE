# ☕ Java Full Course — From Basics to Advanced

> **A structured, beginner-friendly Java learning journey covering Core Java, OOP, Collections, Exception Handling, Multithreading, and Stream API.**

## 📚 What You'll Learn

This course takes you from **Java fundamentals → Object-Oriented Programming → Advanced Java concepts → Collections → Multithreading → Stream API**.

### 🗺️ Learning Path

```text
Java Basics
    ↓
Control Flow
    ↓
Methods & Arrays
    ↓
Strings
    ↓
OOP Concepts
    ↓
Inheritance & Polymorphism
    ↓
Interfaces & Abstract Classes
    ↓
Exception Handling
    ↓
Collections Framework
    ↓
Multithreading
    ↓
Stream API
```
